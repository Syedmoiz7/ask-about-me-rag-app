# Mobile projects

## Ask It World

A Reddit-style social discussion app for iOS and Android, built from scratch with React Native
CLI and 100% TypeScript. State management and data fetching use Redux Toolkit and RTK Query,
talking to REST APIs. The code uses a feature-based folder architecture so it scales as features
are added. It is published on the App Store.

## Cardinal Hearts

An anonymous relationship-support platform with real-time peer interactions, encrypted
messaging and admin moderation tools. Built with React Native (Expo), Node.js, Express,
PostgreSQL, WebSockets and JWT authentication. It has a separate admin dashboard.

## ioMoVo

An AI-powered Digital Asset Management (DAM) mobile app, built at Xtecsoft with React Native
CLI, TypeScript, Redux Toolkit and RTK Query. Users manage, stream and process media stored
across Google Drive, Dropbox and AWS S3 from one app.

Background chunked uploading and file caching improved media processing efficiency by about
20%. Refactoring heavy list components and legacy screens reduced app crashes by about 25%.
