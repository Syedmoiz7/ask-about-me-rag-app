# Tech stack and skills

## Frontend and mobile

React.js, Next.js, TypeScript, JavaScript (ES6+), Tailwind CSS, Redux Toolkit, RTK Query, and
React Native (both CLI and Expo) for iOS and Android.

## Backend and databases

Node.js, Express.js, REST APIs, SQL, PostgreSQL, Prisma ORM, MongoDB with Mongoose, JWT
authentication and WebSockets for real-time features.

## Tools and workflow

Git and GitHub (branching, pull requests, resolving merge conflicts), Postman, Vercel,
Firebase, the Stripe API and Sanity CMS.

## AI and agentic tools

Claude Code and OpenAI Codex for AI-assisted development: implementing features, refactoring,
debugging and API integration. All AI-generated code is reviewed before it ships.

MCP (Model Context Protocol) is an open standard that lets AI agents connect to external tools
and data sources. Moiz has used the Figma MCP server so a coding agent could read design files.

## Currently learning

Python, Django, the OpenAI API, LangChain, embeddings, RAG and vector databases such as FAISS,
Qdrant and Pinecone. This "Ask My Docs" project is part of that learning.
