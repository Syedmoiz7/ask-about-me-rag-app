# Web projects

## Kelsey Scholarship Portal

A multi-tier scholarship portal built at Kamsoft Technologies. Students submit applications,
reviewers score them, and admins make the final decisions. Built with Next.js, Node.js, Express,
PostgreSQL, WebSockets, JWT authentication and Tailwind CSS.

Application tracking and email notifications are automated, which reduced manual
administrative work by about 60%.

The UI was built with an AI-assisted workflow: the Figma MCP server was connected to OpenAI
Codex so the coding agent could read the Figma designs directly and generate UI components.
The generated code was reviewed and refined before merging.

## Architecture Event Marketplace

A commercial multi-vendor event marketplace that connects event organizers, attendees and
platform administrators. Built with Next.js, Node.js, PostgreSQL, the Stripe API for payments,
Sanity CMS for content and Tailwind CSS.
